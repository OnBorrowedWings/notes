# notes

De bron van notes.erwhin.com: gepubliceerde notes en Concept-hubs. Kennis die voor iedereen geldt, met bij elke bewering een label en een referentie.

## Wat staat waar

| Bestand | Wat |
|---|---|
| `index.html` | Startpagina met de lijst van notes |
| `kaders-labels-voor-beweringen.html` | Note: wat de vier labels betekenen. Andere notes verwijzen ernaar. |
| `kaders-metamodel.html` | Concept-hub *Van zorg tot bewijs* |
| `kaders-samenhang.html` | Concept-hub *Van betekenis tot bewijs* |
| `kaders-invloeden.html` | Concept-hub *Wat erop inwerkt* |
| `site.css` | De stylesheet, voorlopig een kopie van die van publicatiehuis |
| `CNAME` | Het adres notes.erwhin.com voor GitHub Pages |

## Afspraken

- **Kennis linkt niet naar een project.** Een note verwijst niet naar pagina's van Publicatiehuis of een essay. Andersom mag wel.
- **Vier labels:** feit, afgeleide, hypothese en interpretatie. Een interpretatie staat niet in een note; die hoort in een view. Zie `kaders-labels-voor-beweringen.html`.
- **Naamgeving:** het voorvoegsel groepeert notes, ongeacht de repository (bijvoorbeeld `kaders-`).
- **Vormgeving:** één `site.css`, geen eigen stijl in pagina's. Kleur alleen voor de assen van het model.
- **AI:** inhoud die met AI is gegenereerd en nog niet door mij is herschreven, krijgt onderaan een vermelding.

De achtergrond van deze afspraken staat in de repository `publicatiehuis` (ADR-011 t/m 013).
